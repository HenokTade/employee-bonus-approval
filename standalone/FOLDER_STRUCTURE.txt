=====================================================
Database Tables Structure
=====================================================

users
├── id (primary key)
├── email (unique)
├── name
├── hashed_password
├── role (RBAC)
├── department
├── clearance_level (MAC: 1-3)
├── after_hours_access (RuBAC)
├── mfa_enabled
├── mfa_secret
├── failed_login_attempts
├── locked_until
├── created_at
└── updated_at

nominations
├── id (primary key)
├── employee_id → users(id)
├── manager_id → users(id)
├── department
├── type (bonus/promotion)
├── bonus_amount
├── promotion_to
├── justification
├── status (pending_*/approved/rejected)
├── level1_approved_by → users(id)
├── level2_approved_by → users(id)
├── level3_approved_by → users(id)
├── rejected_by → users(id)
├── rejection_reason
├── mac_label (MAC: 1-3)
├── owner_id → users(id) (DAC)
├── dac_permissions (JSONB)
├── created_at
└── updated_at

audit_logs
├── id (primary key)
├── user_id → users(id)
├── action
├── details (JSONB)
├── ip_address
├── user_agent
└── timestamp

=====================================================
API Endpoints Quick Reference
=====================================================

AUTHENTICATION:
POST   /api/auth/register        Register new user
POST   /api/auth/login           Login with credentials
POST   /api/auth/logout          Logout user

NOMINATIONS:
POST   /api/nominations          Create nomination
GET    /api/nominations          Get nominations
POST   /api/nominations/:id/approve      Approve
POST   /api/nominations/:id/reject       Reject
POST   /api/nominations/:id/grant-permission  DAC

ADMIN:
GET    /api/admin/users          Get all users
POST   /api/admin/users/:id/update       Update user
GET    /api/admin/logs           Get audit logs
POST   /api/admin/backup         Create backup

UTILITY:
GET    /api/health               Health check

=====================================================
Access Control Implementation Locations
=====================================================

RBAC:
   File: server.js
   Lines: 167-182 (authorize middleware)
   Usage: app.get('/api/admin/users', authenticate, authorize('hr_admin', 'system_admin'), ...)

MAC:
   File: server.js
   Lines: 78-81 (checkMacClearance function)
   Usage: if (!checkMacClearance(user.clearance_level, nom.mac_label)) { ... }

DAC:
   File: server.js
   Lines: 647-686 (grant-permission endpoint)
   Database: nominations.dac_permissions (JSONB)

RuBAC:
   File: server.js
   Lines: 56-76 (checkTimeBasedAccess function)
   Usage: if (!checkTimeBasedAccess(user.after_hours_access)) { ... }

ABAC:
   File: server.js
   Lines: 83-112 (evaluateAbacPolicy function)
   Usage: if (!evaluateAbacPolicy(user, resource, action)) { ... }

=====================================================
Development Workflow
=====================================================

1. FIRST TIME SETUP:
   npm install
   cp .env.example .env
   [edit .env]
   npm run setup-db
   npm start

2. DAILY DEVELOPMENT:
   npm run dev          (auto-restart on changes)
   
3. TESTING:
   npm start            (in one terminal)
   ./test-api.sh        (in another terminal)
   
4. PRODUCTION:
   npm start
   
5. DATABASE RESET:
   npm run setup-db     (drops and recreates)
