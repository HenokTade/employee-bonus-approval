STEP-BY-STEP INSTALLATION FOR YOUR LOCAL MACHINE

========================================================================
1. INSTALL POSTGRESQL
========================================================================

Windows:
--------
1. Download PostgreSQL from: https://www.postgresql.org/download/windows/
2. Run the installer
3. Remember the password you set for the 'postgres' user
4. Keep default port (5432)

macOS:
------
Open Terminal and run:
    brew install postgresql@14
    brew services start postgresql@14

Linux (Ubuntu/Debian):
----------------------
Open Terminal and run:
    sudo apt update
    sudo apt install postgresql postgresql-contrib
    sudo systemctl start postgresql

========================================================================
2. CREATE DATABASE
========================================================================

Open Terminal/Command Prompt and run:

    psql -U postgres

(Enter your postgres password when prompted)

Then type:

    CREATE DATABASE sepbas_db;
    \q

========================================================================
3. INSTALL NODE.JS
========================================================================

Download and install Node.js (v16 or higher) from:
https://nodejs.org/

Verify installation by opening Terminal/Command Prompt:
    node --version
    npm --version

========================================================================
4. SETUP PROJECT
========================================================================

1. Navigate to the 'standalone' folder:
   
   cd path/to/your/project/standalone

2. Install dependencies:
   
   npm install

3. Create environment file:
   
   # Copy the example file
   cp .env.example .env
   
   # OR on Windows
   copy .env.example .env

4. Edit the .env file:
   
   Open .env in any text editor and update:
   
   DB_PASSWORD=your_postgres_password_here
   JWT_SECRET=change_this_to_a_random_string
   
   (Leave other settings as default)

========================================================================
5. INITIALIZE DATABASE
========================================================================

Run this command in the standalone folder:

    npm run setup-db

You should see:
    ✅ Database setup completed successfully!
    
    And a list of sample users created

========================================================================
6. START THE SERVER
========================================================================

Run:
    npm start

You should see:
    🚀 SEPBAS Backend Server Started
    📡 Server running on http://localhost:3000

========================================================================
7. TEST THE SERVER
========================================================================

Open a web browser and go to:
    http://localhost:3000/api/health

You should see:
    {"status":"OK","timestamp":"...","service":"SEPBAS Backend"}

========================================================================
TROUBLESHOOTING
========================================================================

Problem: "Database connection failed"
Solution: 
    - Make sure PostgreSQL is running
    - Check your .env file has correct DB_PASSWORD
    - Verify database exists: psql -U postgres -l

Problem: "Port 3000 already in use"
Solution:
    - Change PORT in .env file to 3001 or another number

Problem: "npm install fails"
Solution:
    - Delete node_modules folder
    - Run: npm cache clean --force
    - Run: npm install again

Problem: "Cannot find module"
Solution:
    - Make sure you're in the 'standalone' folder
    - Run: npm install
